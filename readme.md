# TeamFinder

TeamFinder — это Django-приложение для поиска проектов и участников команды.

Пользователи могут регистрироваться, заполнять профиль, создавать проекты, просматривать проекты других пользователей, добавляться в участники и сохранять понравившиеся проекты в избранное.

## Возможности проекта

- регистрация и авторизация пользователей;
- редактирование профиля;
- автоматическая генерация аватара пользователя;
- просмотр списка участников;
- создание проектов;
- редактирование собственных проектов;
- просмотр карточки проекта;
- добавление и удаление проекта из избранного;
- участие в проектах;
- завершение проекта автором;
- административная панель Django.

## Стек технологий

- Python;
- Django;
- SQLite для локальной разработки;
- PostgreSQL для запуска через Docker;
- HTML;
- CSS;
- JavaScript.
